# Phase 1.1: Directory Structure - Context

**Gathered:** 2026-07-10
**Status:** Ready for planning

<domain>
## Phase Boundary

Directory structure cleanup and asset organization. We are establishing a pristine, strictly categorized directory structure (especially for `Assets`) under the Ponytail Ultra philosophy.

</domain>

<decisions>
## Implementation Decisions

### Game Content Organization
- **D-01:** Move all game content (Characters, Environment, Audio, Animations) into the `Art/` folder rather than keeping them flat in the Assets root.

### Third-Party Assets
- **D-02:** Move Third-Party assets such as LeanTween, Asset Packs, and TextMesh Pro into the `Plugins/` folder.

### Legacy Files
- **D-03:** Delete the `Old Scenes` folder completely. It remains in source control if it is ever needed in the future.

### Root Files
- **D-04:** Move `PlayerData.json` to a `Data/` (or `StreamingAssets/`) directory and move `DefaultVolumeProfile.asset` to a `Settings/` directory.

### Claude's Discretion
Any other loose files in the `Assets/` root should be organized into logical folders (`Scripts/`, `Prefabs/`, etc.) at Claude's discretion to achieve an ultra-clean structure.

</decisions>
