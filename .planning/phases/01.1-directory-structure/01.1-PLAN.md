# Phase 1.1: Directory Structure - PLAN

## Requirements
- ARCH-01
- ARCH-02

## Must Haves
- D-01, D-04: The `Assets/` root directory MUST ONLY contain `Art/`, `Data/`, `Plugins/`, `Prefabs/`, `Scripts/`, `Settings/`, `InputSystem/`, `Resources/`, `Scenes/` and their respective `.meta` files.
- D-02: Every file and folder moved or deleted MUST include its corresponding `.meta` file to prevent Unity GUID breakage.
- D-03: `Old Scenes/` and its `.meta` file MUST be completely deleted.

## Tasks

### Wave 1

```xml
<task>
  <read_first>
    - Assets/
  </read_first>
  <action>
    Move Game Content and their associated `.meta` files into `Assets/Art/`.
    Specifically, execute terminal commands to move the following folders and their `.meta` files from `Assets/` to `Assets/Art/`:
    - `Animations` and `Animations.meta`
    - `Audio` and `Audio.meta`
    - `Characters` and `Characters.meta`
    - `Environment` and `Environment.meta`
    - `Fonts` and `Fonts.meta`
    - `Idle` and `Idle.meta`
    - `Materials` and `Materials.meta`
  </action>
  <acceptance_criteria>
    - Running `ls Assets/Art/` shows `Animations`, `Audio`, `Characters`, `Environment`, `Fonts`, `Idle`, and `Materials`.
    - Running `ls -A Assets/Art/ | grep '\.meta$'` shows all their corresponding `.meta` files.
    - These folders and `.meta` files no longer exist in the `Assets/` root.
  </acceptance_criteria>
</task>
```
