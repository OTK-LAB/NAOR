# Phase 8.1 Plan: Prototype Scene Consolidation

## Objective
Porting and stabilizing prototype scenes with modular initialization from the `NAOR_prototype` repository. Ensure that ported mechanics are cleanly integrated and playable individually in the editor without relying on monolithic managers or bootstrap scripts.

## Threat Model
- **Missing Repository Access:** `NAOR_prototype` repository is currently missing from the workspace. Without the path to the cloned repo, migration cannot occur.
- **Missing References:** Bringing in scenes without their full dependency tree (sprites, materials, prefabs, scripts) will result in broken Unity objects and missing script warnings.
- **Ponytail Ultra Violation:** Carrying over legacy global singletons or monolithic managers from the prototype repository will introduce bloat, violating architecture constraints.
- **Bootstrapping Contradiction:** Adding `#if UNITY_EDITOR` or fallback boot scripts to run scenes individually violates decision D-02. This risk is mitigated by using pure scene-local dependency injection via Unity Inspector, resolving CORE-05 without violating D-02.
- **Collateral Damage:** Unintentional modifications to `Assets/AI_Tools/` generated art or other existing pristine folders during the migration process.

## Execution Steps

### 1. Environment Setup & Repository Linking
- **Action:** Request the absolute path of the cloned `OTK-LAB/NAOR_prototype` repository from the user.
- **Action:** If the user hasn't cloned it locally, instruct them to do so or provide a script to clone it into an adjacent directory (e.g., `/Volumes/aebasol_1tb/Ob/Projects/NAOR_prototype`).
- **Validation:** Confirm the required files (Scenes, Scripts, Prefabs) exist in the provided prototype directory.

### 2. Asset & Level Design Migration
- **Action:** Copy all prototype playable scenes to `Assets/Scenes/Prototype/` in the target repository.
- **Action:** Migrate all required level design assets (Sprites, Tilemaps, Prefabs, Materials) from the prototype to their appropriate respective pristine folders in `Assets/`.
- **Action:** Migrate all relevant C# scripts governing mechanics to `Assets/Scripts/Prototype/` (or similar logical categorization).
- **Constraint Check:** Ensure `Assets/AI_Tools/` is entirely untouched during the copy process.

### 3. Fixing Broken References & Clean Up
- **Action:** Open the project/scenes in Unity to identify any broken `m_Script` references or missing assets.
- **Action:** Update GUIDs in scene `.unity` and prefab `.prefab` files if necessary, or manually reassign scripts within the Editor.
- **Action:** Delete any obvious duplicate assets or explicitly unneeded legacy items that came along with the port.

### 4. Ponytail Ultra Refactoring (Removing Monoliths)
- **Action:** Identify any ported monolithic managers, global singletons (e.g., `GameManager.Instance`), or cross-scene dependencies in the prototype code.
- **Action:** Refactor these scripts into scene-local components. Dependencies should be resolved locally within the scene hierarchy using direct Inspector assignments or `GetComponent` calls on local objects.
- **Action:** Remove any fallback bootstrap logic (`#if UNITY_EDITOR` to load an init scene) that existed in the prototype. Ensure D-02 is strictly respected.

### 5. Modular Initialization Verification (CORE-05 & CORE-06)
- **Action:** For each ported scene, establish an entry-point behavior that cleanly initializes local mechanics on `Awake()` / `Start()`.
- **Action:** Verify that all mechanics ported from the prototype function correctly within these standalone constraints.
- **Validation:** Test that each scene can be opened individually in the Unity Editor and played by pressing Play, without requiring a Dummy Main Menu to bootstrap state.

### 6. Review & Stabilization
- **Action:** Check for any script compilation errors and resolve them.
- **Action:** Confirm that the user can observe the prototype assets and mechanics without legacy bloat (CORE-03).
- **Action:** Update `STATE.md` to reflect the migration and consolidation success.
