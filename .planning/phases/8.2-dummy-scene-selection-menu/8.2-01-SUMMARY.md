## Issues Encountered

**Issue: DummyMainMenu.unity cannot be created headlessly.**
- **Root cause:** Unity `.unity` scene files use binary or YAML serialization managed exclusively by the Unity Editor; they cannot be created or validated outside it.
- **Resolution:** The pre-existing editor script `Assets/Editor/Phase82Setup.cs` (`Tools/Setup Phase 8.2 (Dummy Main Menu)`) performs the full scene creation, saves it to `Assets/Scenes/DummyMainMenu.unity`, and updates Build Settings when executed inside the Unity Editor.
- **Manual step required:** Open the project in Unity, navigate to `Tools > Setup Phase 8.2 (Dummy Main Menu)`, run it. The new `BuildSettingsSetup.cs` (`Tools > Setup Build Scenes for Phase 8.2`) can be run afterward if only Build Settings need to be re-applied without recreating the scene.
