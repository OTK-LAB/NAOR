# Structure

```text
Assets/
├── Animations/          # Animation clips & controllers
├── Audio/               # SFX and music
├── Characters/          # Character assets
├── Environment/         # Level assets
├── InputSystem/         # Unity Input System assets
├── Prefabs/             # Game objects (Canvas, NPCs, etc)
├── Scenes/              # Game levels
└── Scripts/
    ├── Dialogue/        # Dialogue UI and triggers
    ├── Enemies/         # Enemy behaviors (Archer, Sword, Shield)
    ├── Player/          # Player controller, State Machine, Input, Data
    ├── Systems/         # Core managers (Audio, Resource, VFX)
    └── UI/              # Health bars, Inventory, Menus
```
